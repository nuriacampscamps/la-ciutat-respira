# La Ciutat Respira

## Descripció

La Ciutat Respira és un rellotge creatiu desenvolupat amb p5.js i adaptat com a extensió del navegador Firefox. Representa el pas del temps a través d'una ciutat animada que canvia d'aspecte segons l'hora del dia.

## Funcionalitats

- Ciutat animada amb edificis, cotxes, núvols i persones.
- Canvis visuals del cel segons l'hora del dia.
- Rellotge digital amb l'hora actual.
- Controls per pausar i reprendre l'animació.
- Control per modificar la velocitat de la ciutat.
- Temporitzador de concentració de 25 minuts.
- Opcions per començar, pausar i reiniciar el temporitzador.

## Tecnologies utilitzades

- HTML
- CSS
- JavaScript
- p5.js
- Firefox WebExtensions (Manifest V3)

## Com provar l'extensió

1. Descarrega els fitxers del repositori.
2. Obre Firefox i escriu `about:debugging` a la barra d'adreces.
3. Selecciona **This Firefox**.
4. Prem **Load Temporary Add-on…**.
5. Selecciona el fitxer `manifest.json`.
6. Obre l'extensió i prova'n les funcionalitats.
